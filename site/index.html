A REST API built like production

Express 5 API for managing client projects, with validation, consistent errors, pagination, rate limiting, API keys, persistence, Docker and an integration test suite.

View sourceRun it locally

Highlights

Validation

Per-field error messages and a strict schema; unknown fields are rejected.

Query power

Filter by status or tag, full-text search, sort by any field, paginate with metadata.

Security

Fixed-window rate limiter with RateLimit headers and optional Bearer API key for writes.

Observability

Request IDs on every response, timing logs, and JSON 404s and 500s.

Persistence

In-memory store with atomic temp-file-and-rename writes to JSON.

Tested

11 integration tests with node:test and supertest, run in CI on Node 20 and 22.

Run it

Start

git clone https://github.com/Lekopien/node-rest-api
cd node-rest-api
npm install
npm start   # http://localhost:3000

Create and query

curl -X POST localhost:3000/api/projects \
  -H 'content-type: application/json' \
  -d '{"name":"Bakery website","client":"Mama Bakery","budget":450}'

curl 'localhost:3000/api/projects?status=planned&sort=-budget&limit=5'

Response

{
  "data": [{ "id": "6f1c…", "name": "Bakery website", "status": "planned", "budget": 450 }],
  "meta": { "total": 1, "page": 1, "limit": 5, "pages": 1 }
}
